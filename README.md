# ROVTOR

ROVTOR WEB · 1.1.5 Landing Page

GitHub Pages에 그대로 올리거나 `index.html`을 브라우저에서 열 수 있는 정적 랜딩 페이지입니다.

## 링크 설정

실제 다운로드/깃허브 주소가 준비되면 `script.js` 상단의 `CONFIG`에서 아래 두 값만 바꾸세요.

```js
downloadUrl: 'YOUR_DOWNLOAD_URL_HERE',
githubUrl: 'YOUR_GITHUB_URL_HERE'
```

주소를 넣기 전에는 버튼이 이동하지 않고, 친절한 사이트 내 안내 메시지를 표시합니다.

버전별 변경사항도 같은 `CONFIG.releaseNotes` 배열에서 수정할 수 있습니다.
